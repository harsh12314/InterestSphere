## 📖 Overview
In a world overflowing with generalized social networks, finding peers who share your exact interests—whether it’s competitive programming, indie game development, astronomy, or chess—can be challenging. 
**InterestSphere** simplifies social discovery. Users can create interest-focused profiles, explore dynamic community hubs, and connect in real time with like-minded individuals powered by a serverless Firebase backend.
---
## ✨ Key Features
- 🔐 **Seamless Google Authentication:** One-click secure sign-in and session management powered by **Firebase Authentication**.
- 🎯 **Interest Tag Matching & Discovery:** Users can browse and filter members based on granular interest tags and categories.
- ⚡ **Real-Time Data Synchronization:** Instant updates for user profiles, activity feeds, and interactions backed by **Google Cloud Firestore**.
- 📱 **Responsive & Intuitive UI:** Built with **React** and modern CSS for smooth transitions across mobile, tablet, and desktop viewports.
- 🚀 **Blazing Fast Performance:** Bundled with **Vite** for instantaneous page loads and minimal bundle sizes.
- ☁️ **Full-Cycle Cloud Deployment:** Hosted reliably via **Firebase Hosting** with global CDN caching.
